# Showcase (public)

This folder contains **public showcase** content.

Key rules:

- Narrative/commercial model only. **Do not reuse** operational product types, statuses, or IDs.
- No Supabase.
- No imports from `src/lib/services`.
- Deterministic local mock data (marketing/storytelling).

The goal is to implement the Design System reference screens (SSOT: `docs/design/modern-source/`) in a controlled environment before migrating `/app`.
